# 5 GIT COMMANDS

## 1.
` git branch `
## Used to review the list of branches 

## 2. 
` git checkout -b feature/commands `
## Used to create feature/commands named branch, as well switch into feature/commands

## 3. 
` git add . `
## Used to add all changes in files to the staging step (maybe for commit / stash)

## 4.
` git commit -m "Add 5 GIT commands" `
## Used to commit changes also with messages showing "Add 5 GIT commands"

## 5. 
` git push -u origin main `
## Used to push commit to remote repository with upstreaming 

## These are 5 important commands of git which we used normally and daily life tasks
